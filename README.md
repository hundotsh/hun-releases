# Hun releases

Release files for [Hun](https://hun.sh), the menu bar app for the dev servers on your Mac.

This repository holds downloads only:

- **Hun for Mac**: [hun.sh/download](https://hun.sh/download)
- **The `hun` command**: `curl -fsSL https://hun.sh/install.sh | sh`
- **Changelog**: [hun.sh/changelog](https://hun.sh/changelog)

Use the hun.sh links above rather than linking here directly; they always point at the latest release.
